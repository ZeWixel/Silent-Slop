# Silent-Slop

Псевдо-демейк **Silent Hill 1** для J2ME (Sony Ericsson, MIDP-1.0 / CLDC-1.0).
Прототип покрывает пролог (улица, разбитая машина, кафе «5 to 2») и сам уровень
кафе.

Готовые сборки: `releases/SilentSlop.jar` (~66 КБ) + `releases/SilentSlop.jad`.

## Сборка

```sh
JAVA_HOME=/path/to/jdk8 ./build.sh
```

`build.sh` компилирует `src/` вместе с заглушками `stubs/` под `-source 1.3
-target 1.3` (так требует KVM), убирает заглушки `javax/*` и `com/nokia/*` из
архива, кладёт манифест с MIDlet-атрибутами и пишет JAD с размером JAR.

Проверка готового JAR (не дерева сборки):

```sh
JAVA_HOME=/path/to/jdk8 ./tools/verify_jar.sh
```

Скрипт распаковывает `releases/SilentSlop.jar`, грузит `ss.Midlet`, рендерит
оба уровня, проверяет, что в архиве нет заглушек `javax/*` и `com/nokia/*`, и
что все четыре MIDI читаются из JAR.

## Что уже сделано

* **Изометрический рендер без перспективы.** `ss.core.Render3D` — целочисленный
  ортографический конвейер: поворот камеры по вертикали 30°, свободный поворот по
  горизонтали, аффинная текстура (без коррекции), near-clipping по `ZNEAR`,
  отсечение по bounding-box в экранном пространстве, painter-сортировка граней
  с флашем буфера.
* **Туман как оптимизация.** `fogOf()` считает уровень тумана на грань, а
  `emitClipped` не тратит пиксели на то, что всё равно уходит в туман; дальние
  бэнды вообще не подаются в растеризатор.
* **Освещение.** Плоская заливка + направленный свет (`MODE_FLAT`) и
  аффинная текстура + направленный свет (`MODE_TEX`); меши уровня — только
  аффинная текстура.
* **Отсечение стен между камерой и игроком.** Грани, которые ближе игрока и
  накрывают его силуэт, выкидываются по экранному bbox (`overPlayer`), а не
  целиком бэнд — поэтому кафе и улица остаются читаемыми при любом повороте.
* **Уровни в реальных метрах** (`Level.U = 40 см`, бэнд 480 см) — полосы дороги,
  тротуары и газоны больше не перекрываются, z-fighting нет.
* **Графика** генерируется процедурно (`ss.gen.Gen`, `Models`): палитра 64 цвета,
  52 текстуры, 22 модели в стиле PSX.
* **Звук.** Четыре MIDI-трека в `res/m/` (`tools/mkmidi.py`), сгенерированы
  процедурно — оригинальные треки не распространяются. SFX (радио-шум, подбор,
  выстрел/удар, смерть врага, сирена) — `ss.snd.SfxGen`.
* **Визуальная новелла** в стиле *Play Novel: Silent Hill* (`ss.vn`).
* **Интерфейс.** Карта (`#`), инвентарь (левая софт-клавиша), пауза и dev-меню с
  FPS, кучей, координатами, god mode и выбором уровня.

## Управление

| Клавиша | Действие |
|---|---|
| 2 / 4 / 6 / 8 | движение (8 направлений) |
| 5 | атака / подтверждение / поиск |
| двойное нажатие направления | бег |
| `*` | прицеливание |
| `#` | карта |
| 0 | фонарик |
| 1 / 3 | орбита камеры |
| 7 / 9 | зум |
| правая софт-клавиша | пауза / пропуск |
| левая софт-клавиша | инвентарь |

На карте: `0` — зум, `#` / правая софт — закрыть, `*` / левая софт — этаж.

## Разработка без телефона

`tools/dev/` — desktop-харнесс (в JAR не попадает):

```sh
find src stubs tools/dev -name '*.java' > build/devsrc.txt
javac -nowarn -g -d build/dev @build/devsrc.txt
java -cp build/dev Preview     # 8 поворотов пролога + 4 кафе в /tmp/shots/*.png
java -cp build/dev Smoke       # 4000 кадров случайного ввода во всех экранах
java -cp build/dev Combat      # спавн врага, ближний бой, смерть
java -cp build/dev Wrap        # проверка переносов текста и ширины подписей
java -cp build/dev Menus       # скриншоты паузы и dev-меню, переключение опций
```

## Правовой статус

Фанатский некоммерческий прототип. Silent Hill — торговая марка Konami.
Геометрия уровней восстановлена по открытым данным проекта
`silent-hill-decomp`; все текстуры, модели и музыка сгенерированы кодом в этом
репозитории.
